Multi Profile for Claude · 0.1.0

Install and set up Multi Profile for Claude

Run several Claude accounts side by side on your Mac. Each profile gets its own app, sign-in and chats, plus an optional terminal command for Claude Code. Setup takes about five minutes.

DDefault — your original Claude WClaude Work PClaude Personal

Before you start

  • macOS 13 Ventura or laterApple silicon or Intel.
  • Claude desktop appInstalled in /Applications. Download Claude
  • Claude Code (optional)Only needed for terminal commands like claude-work.

Your existing Claude app becomes the Default profile. Multi Profile for Claude never changes it or its data.

Install

One command installs the app into /Applications. Homebrew adds the tap the first time.

brew install --cask manhduc-nguyen/tap/multi-profile-for-claude

The app is free and isn't notarized by Apple, so the cask clears macOS's download quarantine flag after installing. You can read the cask first at github.com/manhduc-nguyen/homebrew-tap.

To update later:

brew upgrade --cask multi-profile-for-claude

  1. Download Multi-Profile-for-Claude-0.1.0.zip from GitHub Releases, unzip it and drag the app to /Applications.

  2. Because the app isn't notarized, macOS blocks it the first time. Clear the flag in Terminal:

    xattr -dr com.apple.quarantine "/Applications/Multi Profile for Claude.app"

    Or open the app once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.

Needs Xcode 16 or later (or its command line tools with Swift 6). Apps you build yourself aren't quarantined, so they open without a warning.

git clone https://github.com/manhduc-nguyen/multi-profile-for-claude.git
cd multi-profile-for-claude
scripts/install.sh

install.sh builds the app and copies it to ~/Applications, then opens it.

First launch

Multi Profile for Claude lives in the menu bar, not the Dock. After you open it, look for its icon near the clock. Once a profile is in front, the icon shows that profile's colored letter.

Wi‑FiWThu 23 Oct 10:42

On a crowded menu bar, macOS may hide the icon. Go to System Settings → Menu Bar (or Control Center on older macOS) and allow Multi Profile for Claude.

Create a profile

  1. Click the menu bar icon and choose New Profile….

  2. Type a name, for example Work, and pick a color. The preview shows the icon you'll see in the Dock.

  3. Keep Also create a terminal command checked if you use Claude Code. For Work the command is claude-work.

  4. Click Create Profile. It copies Claude, sets the name and icon, signs the copy for your Mac and creates its data folder. This takes a few seconds and uses almost no extra disk space.

The new app, Claude Work, appears in ~/Applications/Claude Profiles, in Spotlight and in Launchpad. Open as many profiles at once as you like and switch with ⌘ Tab.

Sign in to each profile

Choose Open and Sign In after creating a profile, or Sign In… in the Profiles window. For the next 10 minutes, sign-in links from your browser go to that profile instead of your original Claude app.

  1. Check your browser account. If your browser is already signed in to claude.ai with a different account, sign out there first, or paste the sign-in link into a private window.

  2. Sign in from the profile's window using email or Google.

  3. Allow keychain access once. macOS asks whether the profile may use “Claude Safe Storage”. Enter your Mac login password and choose Always Allow.

  4. Click I'm Signed In. Sign-in links go back to your original Claude app.

Profile apps support email and Google sign-in. Passkeys, hardware security keys and Microsoft single sign-on depend on the original app's signature, so use them in your Default profile.

Terminal commands

Each profile can have its own Claude Code command. It keeps a separate Claude Code sign-in, settings and history, and accepts every option claude does.

TypeWhat happens
claude-workStarts Claude Code with the Work profile. The first time, sign in with your Work account.
claude-personal -cContinues your last Personal conversation.
claudeUnchanged. Still uses your Default account.

Commands are small scripts in ~/.local/bin. Use the terminal button next to a profile in the menu, or Open in Terminal in the Profiles window, to start one without typing. The first time, macOS asks to let the app control Terminal.

If Terminal says command not found, add ~/.local/bin to your PATH, then open a new Terminal window:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

After Claude updates

Your original Claude app updates itself. Profile apps keep running the version they were made from until you rebuild them. When that happens, the menu shows Claude was updated. Click Rebuild; sign-ins and chats are kept. Quit a profile before rebuilding it, or let the app quit it for you.

After a rebuild, macOS may ask for “Claude Safe Storage” access once more. Choose Always Allow again.

Troubleshooting

“Multi Profile for Claude” can't be opened because Apple cannot check it

The quarantine flag is still set. Run the command below, or use Open Anyway in System Settings → Privacy & Security.

xattr -dr com.apple.quarantine "/Applications/Multi Profile for Claude.app"
A profile opened my main account instead of a new one

The browser finished signing in with the account it already had. Sign out of claude.ai in the browser (or use a private window), then choose Sign In… for the profile again.

The sign-in link opened my original Claude app

Sign-in links only go to a profile while its sign-in assistant is open, for up to 10 minutes. Choose Sign In… again and finish within that time.

A profile won't open after Claude updated

Choose Rebuild for that profile in the Profiles window. Its data folder isn't touched.

claude-work says it already exists

Something else in ~/.local/bin already uses that name, so the app suggests claude-work-2 and leaves your file alone. Commands made by this app contain the line # Created by Multi Profile for Claude.

Uninstall

First choose Profiles → Remove All Profiles… in the app's menu (shown while the Profiles window is open). It removes every profile app and terminal command it created, and asks whether to keep their chats and sign-ins. Then remove the app:

brew uninstall --cask multi-profile-for-claude

Add --zap to also delete profile apps and their data. Without Homebrew, run scripts/uninstall.sh from the source folder (add --data to delete profile data). Your original Claude app is never touched.
